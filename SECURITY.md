# Security policy

## Supported versions

Harbor & Hearth is a static demonstration storefront. The latest version on the `main` branch is the supported version.

## Reporting a concern

Please do not open a public issue for a suspected security problem. Contact the repository owner privately through GitHub with:

- A clear description of the issue.
- The affected page or file.
- Steps to reproduce the behavior.
- Any suggested mitigation or evidence that helps confirm the report.

The maintainer will acknowledge the report when possible, investigate the issue, and coordinate a fix before public discussion when the issue could affect visitors or contributors.

## Scope

Reports about exposed credentials, unsafe third-party resources, unexpected form behavior, or privacy-impacting changes are welcome. Please avoid submitting real personal data or payment information in reports.
