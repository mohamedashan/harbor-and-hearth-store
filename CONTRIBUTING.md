# Contributing to Harbor & Hearth

Thanks for helping improve this small storefront.

## Local preview

Open `index.html` directly in a browser, or run a simple static server from the project directory:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Project boundaries

This project intentionally uses semantic HTML only. Do not add CSS files, JavaScript files, inline styles, or script tags unless the project direction changes in a future decision.

## Content and accessibility

Keep page language clear, use one meaningful `h1` per page, preserve logical heading order, label every form control, and use descriptive link text. Check keyboard-friendly native HTML elements such as links, buttons, lists, tables, and forms before opening a pull request.

## Pull requests

Explain the user-facing improvement, keep changes focused, and check that internal links resolve. A pull request should include a short testing note describing how the static pages were reviewed.
